WINVINAYA MIS — LOADING SPINNERS
=================================

Animated SVG loaders built for WinVinaya MIS.
Animation is native SMIL — loops continuously, zero extra CSS/JS required.

Files
-----
winvinaya-spinner-logo.svg              WinVinaya flame mark with orbiting brand-colored pulses
winvinaya-spinner-G2-dual-ring.svg       Two counter-rotating rings around the brand mark
winvinaya-spinner-G1-outer-ring.svg      Static mark inside one sweeping ring
winvinaya-spinner-G3-breathing-ring.svg  Ring grows/shrinks while rotating
winvinaya-spinner-F3-draw-erase.svg      Draws on, then erases off
winvinaya-spinner.svg                   Default system loader (alias to winvinaya-spinner-logo.svg)

Colors
------
Brand palette: #FF8500 (orange), #88B74F (green), #9F4E0C (brown)
Transparent background — seamlessly blends onto dark or light surfaces.
